# Settings AI UI

AI-related settings pages and supporting widgets live here:

- LLM profile management and runtime checks.
- Model bundle management.
- Provider data disclosure and document-recognition privacy controls.
- AI transparency history and trace detail views.

Keep route-level pages in this directory. Page-internal part files live in
screen-specific subdirectories such as `llm_credentials/`, `models/`, and
`transparency/`.

Keep non-AI settings pages in `features/settings/ui/`.
