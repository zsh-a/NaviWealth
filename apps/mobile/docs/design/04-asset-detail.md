# 04 · 资产详情 / Asset Detail

## 1. 目标

- 看一只资产的全貌：估值、走势、持仓批次、历史交易、分红/拆股事件。
- 从这里启动新交易、问 AI、设置标签。

## 2. 信息架构

```
AssetDetail
├── Header：名称 / Symbol / 标签 / 账户
├── KPI 区：估值 / 数量 / 平均成本 / 持有时长 / 累计回报 / 今日 P/L
├── 价格走势图（分时 / 1D / 1W / 1M / 3M / YTD / 1Y / ALL）
├── Tab 切换
│   ├── 持仓 (Lots) — 批次表
│   ├── 交易 (Activity) — 流水（买/卖/分红/拆股/转账）
│   ├── 事件 — 公司公告、分红派发预告
│   └── 备注 — 自由文本笔记
└── 底部操作栏：[+] 买入 [-] 卖出 [⋮ 更多 (分红/拆股/调成本/归档)]
```

## 4. KPI 区设计

6 个 KPI（mobile 2×3 网格 / desktop 单行）：

| KPI | 计算 | 备注 |
|------|------|------|
| 估值 | `qty × price_local × fx` | tabular |
| 数量 | `qty` | 整数或带小数（按资产精度） |
| 平均成本 | `avgCost`（FIFO/移动平均，可在 Settings 里切） | |
| 累计回报 | `(value - cost - fees + dividends) / cost` | 同时显示金额 + 百分比 |
| 持有时长 | `now - earliestBuy` | 1y 4m 17d 格式 |
| 今日 P/L | `qty × (price - prevClose)` | |

KPI 之间细分隔线 1dp `outlineVariant`（mobile 网格） / `outline` 0.5dp 垂直分隔（desktop 行）。

## 5. 图表区

- **数据**：分时（intra-day 5 分钟）/ 日线 K（≥1W）；K 线/折线可切。默认折线。
- **交互**：
  - touch：长按出十字线 + 显示日期/价格 tooltip。
  - mouse：hover 同上；ctrl+滚轮缩放横轴；shift+drag 平移。
  - 双击：返回默认时间范围。
- **覆盖层**：勾选后叠加事件标记 — 红色三角 = 卖出、蓝色三角 = 买入、绿色圆点 = 分红、紫色 ✕ = 拆股。
- **空态**：无行情时显示"暂无价格数据，仅展示交易点"。

## 6. Tab 内容

### 6.1 批次（Lots）

每行：数量、入场单价（原币）、日期、当前估值、盈亏（金额 + %）。可点行展开看包含的交易（部分卖会拆 lot）。

桌面表格列：`数量 | 入场价 | 日期 | 持有日 | 现值 | 浮盈 | 浮盈%`，可按列排序。

### 6.2 交易（Activity）

时间倒序，按月分组（Sticky Header）。每条：
```
2025-08-04   买入   20 股 × ¥142 = ¥2,840  fees ¥10
2025-06-30   分红   ¥85  (DPS ¥0.85 × 100)
2025-04-15   拆股   1 → 4   持仓 100 → 400
2025-01-22   买入   30 股 × ¥138 = ¥4,140
2024-08-15   买入   50 股 × ¥125 = ¥6,250
```

行点击 → 弹出该笔详情 + 编辑/删除按钮。

### 6.3 事件

公司公告、分红预告、拆股、退市预警等（依赖市场数据集成）。无数据时隐藏 Tab。

### 6.4 备注

Markdown 单独 textarea，自动保存（500ms debounce）。

## 7. 底部 / 顶部操作栏

| 平台 | 位置 | 主要按钮 | 次要 |
|------|------|---------|------|
| mobile | 底部 sticky | [买入] [卖出] | [⋮ 更多] → 分红/拆股/调成本/复制/归档/删除 |
| tablet | 顶部 AppBar 右 | [+ 交易 ▾] 下拉 | 同 |
| desktop | 顶部 AppBar 右 + 快捷键 `b` 买 / `s` 卖 / `d` 分红 | | |

## 8. Hi-Fi 规格（增量）

| 元素 | Light | Dark |
|------|-------|------|
| 价格图区 fill | 涨：`〈color.gain.cn〉` 18% / 跌：`〈color.loss.cn〉` 18% | 同 alpha |
| 价格图线 | 涨/跌 实线 1.5dp | 同 |
| 十字线 | `〈color.fg.muted〉` 1dp 虚线 | 同 |
| 事件标记 | 见上 6.5 | 颜色 dark 下 +10% 亮度 |
| KPI 分隔线 | `〈color.border.subtle〉` (M3: outlineVariant) | 同 |

## 9. 边界状态

| 状态 | UI |
|------|-----|
| 持仓为 0（已清仓但保留） | KPI 显示历史最大估值 + "已清仓" 徽章 |
| 行情缺失 | 估值显示 `¥ —` + 标签 "数据陈旧 14:00" |
| 仅一笔交易 | 不显示批次切分提示 |
| 货币转换缺汇率 | KPI "估值 — (汇率缺失)" + Banner 跳到 Settings |

## 11. 走查检查项（节选）

- [ ] 拆股后 lot 数量是否正确反映（拆股因子）？
- [ ] 跨币种持仓的"累计回报" 显示是否正确（基础币种 vs 原币）？
- [ ] 长按价格图的十字线是否有触觉反馈？
- [ ] 桌面端 Tab 切换是否保留滚动位置？
- [ ] 屏幕阅读器对图表点提供文本替代（"3 月 1 日收盘 ¥152.30"）？
