# 07 · FIRE 财务自由追踪

## 1. 目标

- 量化"距离财务自由还有多远"。
- 让用户在不同假设（储蓄率、收益率、目标支出）下做敏感度。
- 每月给一次"是否在轨"的反馈。

## 2. 信息架构

```
FIRE
├── Hero：进度条 + 预计达成日期
├── 关键参数（可点击编辑）
│   ├── 年支出（CNY）
│   ├── 提取率 SWR (默认 4%)
│   ├── 目标净值 = 年支出 / SWR
│   ├── 当前储蓄率
│   └── 假设年化收益
├── 净值轨迹图（历史 + 预测扇形）
├── 里程碑列表（25% / 50% / 75% / FIRE）
├── 敏感度分析（小型滑块）
└── 月度对账（"上月储蓄了多少？是否在轨？"）
```

## 4. 计算说明

- **目标净值** = 年支出 / SWR（默认 4%；用户可改 3%–5%）。
- **预测**：蒙特卡洛（1000 次），假设年化收益 + std；每次模拟使用 N(μ, σ²) 复利；输出 5/50/95 分位。
- **ETA (中位)**：用 50% 分位曲线穿越目标线的日期。
- **储蓄率**：(过去 12 月总储蓄) / (过去 12 月总收入)；用户可手动覆盖。
- **里程碑**：固定 25/50/75/100%；显示预计达成日（基于中位预测）。

## 5. 关键交互

- **敏感度滑块**：拖动时只重算预测 + ETA，不动历史；释放后才落库。
- **参数编辑**：BottomSheet（mobile）/ Dialog（desktop）；保存后立即重算。
- **轨迹图缩放**：横轴可拖；预测扇形随之延伸。
- **里程碑通知**：当跨越某里程碑时（与上次状态比较），登录后弹一次祝贺动画 + Snackbar。
- **不在轨** banner：当过去 6 个月平均储蓄率显著低于假设时，顶部黄色 banner "近 6 月储蓄率 22% < 假设 38%，FIRE ETA 推迟到 2034-04。"

## 7. 边界状态

| 状态 | UI |
|------|-----|
| 历史 < 6 个月 | 不显示储蓄率与不在轨 banner；提示"再积累几个月数据后此处更可靠" |
| 目标 < 当前 | "你已经实现 FIRE 🎉"，进度 100%，预测变成"安全提取年限" |
| 年支出未填 | 引导 onboarding 卡 "先告诉我年支出来开启 FIRE 追踪" |
| 蒙特卡洛模拟禁用（性能） | 退化为单点确定性预测（直线）+ 标注 "deterministic" |
