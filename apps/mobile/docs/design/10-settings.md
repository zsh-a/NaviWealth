## 3. 数字与货币展示规范

> 这是 FIR-22 中"涨跌色 + 数字展示"的延伸约定，所有页面遵守。

### 3.1 千分位

- 中文区：默认 `1,283,452.10`（西式千分位）。
- 用户可切到 `128,3452.10`（中式万分组）—— 仅在"金额 ≥ 1 亿" 时建议关闭。
- 实现：`intl.NumberFormat`。

### 3.2 小数位

- 货币：默认 2 位（CNY/USD/HKD/EUR），日元 0 位。
- 数量：股票 4 位 / 加密 8 位 / 现金 2 位。
- 百分比：默认 2 位（`+8.21%`），变动 < 0.01% 显示 `0.00%`（不染色）。

### 3.3 缩写大数字

| 阈值 | 缩写 | 例 |
|------|------|----|
| < 10k | 全数字 | ¥8,452 |
| 10k–1M | 不缩 | ¥128,452 |
| 1M–100M | `M` 或 `万` (按设置) | ¥1.28M / ¥128.45 万 |
| ≥ 100M | `亿` 或 `B` | ¥1.28B / ¥1.28 亿 |

> 中文用户默认走"万/亿"，国际默认走"k/M/B"。Hero 净值卡只在用户开启"大数缩写"时启用。

### 3.4 涨跌符号

- 默认：`▲`（涨）/ `▼`（跌）/ `—`（持平）+ 颜色。
- 可访问性：色盲用户即使关掉颜色，三角图标仍传达方向。

### 3.5 颜色语义统一

| 语义 | CN 默认 | Intl 默认 | 备注 |
|------|---------|-----------|------|
| 涨 | 红 | 绿 | `〈color.gain〉` |
| 跌 | 绿 | 红 | `〈color.loss〉` |
| 卖出操作 | 橘（warn） | 同 | 与涨跌解耦，避免 confused with red/green |
| 买入操作 | 蓝（info） | 同 | |
| 警示 | `error` | 同 | |
| 成功 | `success` | 同 | |

## 4. 字体大小

跟随 `MediaQuery.textScaleFactor`；加上一个自定义滑块覆盖（关闭后才回退到系统）。

| 选项 | 倍率 |
|------|------|
| S | 0.85 |
| M | 1.00 |
| L | 1.20 |
| XL | 1.40 |
| 跟随系统 | system |

## 5. 应用锁

- 启用后，应用进入前台需 Face ID / Touch ID / 数字密码。
- 失败 5 次 30 分钟锁定。
- 平台兼容：iOS / Android `local_auth`；Web 用一次性 PIN（无生物识别）。
- 与 SQLCipher 解锁绑定（FIR-16）：应用锁通过后才解出 DB key。

## 6. 数据导入 / 导出

- **导出**：JSON / CSV（每个表一个文件）/ 加密 backup（`.nwbak`，AES-256，详见 FIR-16 backup）。
- **导入**：CSV 批量交易、富途 / 老虎 / Snowball / Sina 模板（按 FIR-5 落地后扩展）。
