# 09 · AI 对话 / Chat

## 1. 目标

- 用自然语言查询、解释自己的组合（"我去年股票涨了多少？"、"AAPL 占比是不是太高了？"）。
- 让 AI 引用具体本地数据（带链接到资产 / 分析视图）。
- 明确边界：**不给投资建议**，只做数据解释、计算、对比。

## 2. 信息架构

```
Chat
├── 顶部 AppBar：模型 / 隐私模式 / 清空
├── 上下文卡（chip）：当前会话锚定到哪些资产 / 时段 / 视图
├── 消息流（用户 / AI 交替）
│   ├── AI 回答 + 引用块（带链接）
│   ├── 表格 / 图表 inline
│   └── 操作按钮：复制 / 引用到下一条 / 反馈 👍 👎
├── 输入区
│   ├── 多行文本框 + 发送按钮
│   ├── 快捷 Prompt Chips（"我今天涨多少？" "上个月支出多少？"）
│   └── 附件：截图 / 上传 CSV (实验)
└── 底部免责声明 + 模型版本
```

## 4. 消息组件细节

| 类型 | 显示 |
|------|------|
| 用户消息 | 右对齐气泡 `primary.container`，最大宽 70%，圆角 16dp（左下尖 8dp）|
| AI 文本 | 左对齐 markdown 区域，无气泡（占满列宽），头像/标签 `AI` chip |
| AI 表格 | 内嵌迷你表格组件，超过 6 行折叠 + 展开按钮 |
| AI 图表 | 高 240dp 内嵌图，可点开放大；只读 |
| 引用块 | 折叠区，标签 "引用 (3)"，展开列具体来源（带跳转链接）|
| 错误 | "AI 调用失败" + [重试] |
| 流式 | AI 文本逐 token 显示，光标 ▌动画，未完成时禁止编辑上一条 |
| 风险标记 | 当用户问"我该买什么"等建议类问题时，AI 必须返回拒绝模板（见 6） |

## 5. 上下文卡

- Chip 栏在顶部展示"AI 看到的范围"：资产 / 时段 / 当前 Tab。
- 默认随入口决定：从资产详情打开 → 锚定该资产；从 Dashboard 打开 → 锚定整组合 + 当日。
- 用户可手动 ✕ 删除或 + 增加。
- 每次 Chip 改变，下条问题会附上更新后的上下文摘要。

## 6. 安全 / 边界

- **拒绝模板**：当问题被 classifier 识别为"投资建议 / 个股推荐 / 预测涨跌" 时，AI 回答以模板开头：
  > 我不能给具体的买卖建议或股价预测。但我可以帮你理解组合现状或对比历史表现 — 你想从哪个角度看？

- **隐私模式**：Toggle on 后，发送给 LLM 的提示中数字脱敏（保留比例与变动方向，但不发绝对金额；如 "估值 ¥158k" → "估值 高位"）。
- **数据范围**：所有附给 LLM 的数据来自本地 DB；不发送账户密码、PII、未脱敏的服务器 token。
- **免责声明**：始终在底部 1 行可见。

| 元素 | Light | Dark |
|------|-------|------|
| 用户气泡 BG | `primary.container` | 同 |
| 用户气泡 文字 | `onPrimaryContainer` | 同 |

| 输入区 | `surfaceContainerHighest` 圆角 24dp | 同 |
| 免责文字 | `onSurfaceVariant` `type.label.sm` 12sp | 同 |

## 8. 关键交互

- **流式输出**：60–120 tok/s 视觉速度；可点 [停止生成]。
- **复制**：长按 / 右键 / [复制] 按钮，复制纯文本（去 markdown 标记）。
- **引用跳转**：点击引用项跳到对应资产 / 分析视图，AppBar 留 ← 返回按钮。
- **键盘**：`⌘ + ↵` 发送、`Esc` 关闭 Drawer、`↑` 编辑上一条用户消息（如 ChatGPT）。
- **会话**：mobile 单会话；desktop 支持侧边"会话历史"列表（`+` 新建、长按重命名）。
- **附件**：CSV (≤ 5MB) → 提取摘要后入 prompt；图片（理解 + 引用），仅用于私有 / 实验。

## 9. 边界状态

| 状态 | UI |
|------|-----|
| 离线 | 输入框禁用 + banner "AI 需要网络"；可读历史 |
| 模型故障 | 错误气泡 + [切换模型] [重试] |
| 上下文过长 | 自动总结 + 提示 "已根据最近 10 轮对话回答" |
| 限流 | 提示 "本月配额剩余 12 次" 并允许切自托管模型（如有） |

## 11. 走查检查项（节选）

- [ ] 屏幕阅读器是否可读 markdown 表格？
- [ ] 用户连续点击 [发送] 是否会重复消息？应当 throttle。
- [ ] AI 回答中含 "可能"、"也许" 等不确定词时，文本展示是否避免误读为建议？
- [ ] 引用项失效（资产已删）时跳转是否优雅降级？
- [ ] mobile 软键盘弹起时输入区是否随之上移？
- [ ] 隐私模式开启后，messages.userVisible 内容应保留原值，仅"出站 prompt" 脱敏。
