# 06 · 组合分析 / Analytics

## 1. 目标

- 解释"为什么涨/跌"：拆解收益来源（资产 / 时间 / 大类 / 行业）。
- 量化"我做得好不好"：对比基准（沪深 300、S&P 500、自定义）。
- 探索"我钱怎么分布"：大类、行业、地域、币种、流动性、期限。

## 2. 三张子页（Tabs）

```
Analytics
├── 收益率 (Returns)         ← 默认
├── 配置 (Allocation)
└── 流动性 / 期限 (Liquidity)
```

URL：规划中心下的 `/plan/analytics`。收益、配置、流动性作为页内视图切换，不再暴露旧的顶层分析路径。

## 4. 关键计算

| 指标 | 公式 | 备注 |
|------|------|------|
| TWR | 时间加权收益率 | 与现金流频次无关，便于对比基准 |
| MWR / IRR | XIRR(现金流, 日期) | 用 `decimal` 包，迭代法 |
| 累计回报 | (期末 + 累计分红 - 期初 - 累计净流入) / 期初 | |
| 最大回撤 | min((NAV_t - peak) / peak) | 滑窗 |
| 归因（一阶） | 大类权重 × 大类回报 - 总回报 |  |

> 计算由收益率与基准比较服务提供；本文件只规范 UI 显示。

## 5. 图表交互

- **时间区间**：SegmentedButton；选择后所有 KPI 与归因同时重算。
- **多基准**：最多 3 条；颜色取自 `accent` 序列；可独立开关。
- **缩放**：desktop ctrl+滚轮缩放横轴；mobile 双指捏。
- **数据点 tooltip**：日期、组合 / 各基准对应值。
- **空数据**：当时间区间 < 数据起点时，提示"该范围内无数据"。

## 6. Hi-Fi 规格（增量）

| 元素 | Light | Dark |
|------|-------|------|
| 主曲线 | `〈color.brand.primary〉` 2dp | 同 |
| 基准曲线 1 | `〈color.accent.cyan〉` 1.5dp 虚 | 同 |
| 基准曲线 2 | `〈color.accent.purple〉` 1.5dp 虚 | 同 |
| 区域填充 | 主曲线 12% alpha | 18% |
| 进度条目标线 | `〈color.fg.muted〉` 1dp 虚线 | 同 |
| 偏离 ≥ 5% 警示 | `error.container` 背景 | 同 |

颜色序列：`accent` palette 至少 6 色（青、紫、橙、绿、粉、黄），暗色下亮度 +10%。

## 7. 边界状态

| 状态 | UI |
|------|-----|
| 数据点 < 2 | 不绘曲线；显示"数据不足，至少需要 2 个数据点" |
| 时间窗内净流入为 0 | TWR/IRR 仍可算；不显示 IRR |
| 选择多基准但本地缺数据 | inline 提示 + "去添加基准数据源" |
| 大数据集（>5y 日线）| 自动降采样（按月/周）保持流畅 |
