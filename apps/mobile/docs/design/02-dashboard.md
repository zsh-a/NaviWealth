# 02 · Dashboard / 总览

## 1. 目标

- 30 秒内回答四个问题：
  1. 我现在多少钱？（净值）
  2. 今天涨/跌了多少？（日 P/L）
  3. 钱在哪？（大类分布）
  4. 距离财务自由还有多远？（FIRE 进度）

- 副目标：异常、待办（如未补登交易、行情失败、再平衡偏离过大）。

## 2. 信息架构

```
Dashboard
├── Hero：净资产 + 同比/今日 P/L（含币种切换）
├── 快捷操作：[+] 添加交易 / [+] 添加资产 / 问 AI
├── 资产分布卡（饼图 + Legend）
├── 持仓 Top N 卡（mobile 3 / desktop 8）
├── FIRE 进度卡（横向进度条 + 关键里程碑）
├── 异常 / 待办卡（仅在有内容时出现）
└── 同步状态尾栏（最后同步时间、错误重试）
```

## 4. Hi-Fi 规格

### 4.1 颜色 Token

| 元素 | Light | Dark | 备注 |
|------|-------|------|------|
| 页面背景 | `〈color.bg.canvas〉` (M3: surface) | (M3: surface) | dark 略偏冷 |
| 卡片背景 | `〈color.bg.surface〉` (M3: surfaceContainerLow) | (M3: surfaceContainer) | |
| 主文 | `〈color.fg.primary〉` (M3: onSurface) | | |
| 副文 | `〈color.fg.muted〉` (M3: onSurfaceVariant) | | |
| 涨色 (CN 默认) | `〈color.gain.cn〉` `#D9514E` | `#FF6E68` | red |
| 跌色 (CN 默认) | `〈color.loss.cn〉` `#1F9D55` | `#3DBE7A` | green |
| 涨/跌（国际） | `green / red` 反转 | | 设置项可切换 |
| 中性零变动 | `〈color.fg.muted〉` | | 0.00% 不染色 |
| 强调（CTA） | `〈color.brand.primary〉` (M3: primary) | | |

色盲友好：除颜色外，所有涨/跌带 ▲ ▼ 三角图标（不依赖颜色识别）。

### 4.2 字号 / 类型 Token

| 用途 | Token | 大小 / 行高 / 字重 |
|------|-------|---------------------|
| Hero 净值 | `type.display.lg` | 36 / 44 / 600, tabular |
| 卡片标题 | `type.title.md` | 16 / 22 / 600 |
| 大类百分比 | `type.title.sm` | 14 / 20 / 600, tabular |
| 资产名称 | `type.body.md` | 14 / 20 / 500 |
| 副信息 | `type.label.md` | 12 / 16 / 400 |
| 表格金额 | `type.body.md` tabular | 14 / 20 / 500 |

### 4.3 间距 / 圆角

- 卡片圆角：`radius.lg` = 16dp（沿用现有 `AppTheme.cardTheme`）。
- 卡片内 padding：mobile 16 / tablet 20 / desktop 24。
- 卡片间垂直间距：`space.3` = 12dp。
- 模块间分组留白：`space.5` = 24dp。

### 4.4 阴影

- 卡片：`elevation.0`（M3 屏外观无阴影，靠表面色对比）；hover 时升至 `elevation.1`（仅 desktop）。
- 浮层（FAB / BottomSheet 顶部）：`elevation.3`。

## 5. 关键交互

### 5.1 数字滚动入场
首次加载（或下拉刷新后），净值与所有金额从 0 → 最终值滚动 600ms，曲线 `easeOutCubic`。后续刷新只播 200ms 涨跌闪烁（背景色短暂染涨/跌色 12% alpha）。

### 5.2 下拉刷新
- 触发：所有平台支持下拉。
- 动作：拉取行情 → 重算估值 → 更新 P/L 卡。
- 反馈：顶部 ProgressIndicator + 完成后 Snackbar "已更新 14:32"。

### 5.3 空态
- 首次：净值卡显示 `¥ —`，CTA "添加你的第一项资产" 占满下方区域，其他卡隐藏。
- 长期空：加导引插画 + 文案"还没有数据，先来添加一笔交易"。

### 5.4 错误态
- 行情失败：在净值卡右上角小图标 ⚠️ "行情数据陈旧 14:00"，点击查看哪个数据源失败 + 重试。
- 同步失败：AppBar 同步指示变 ○ 红色，点击进入 Snackbar "无法连接服务，重试 / 离线模式"。

### 5.5 局部加载（骨架屏）
- 首次进入但本地无缓存：每张卡显示骨架（圆角矩形 + 文字条占位），不显示 spinner。
- 已有缓存：直接展示历史值，背景内静默刷新；完成后数字闪烁。

## 6. 响应式细节

- **Hero 净值**：mobile 占满宽，desktop 限宽 720 居左。
- **资产分布饼图**：mobile 居中 200dp 圆；tablet 240dp + 右侧 Legend；desktop 280dp + Legend。
- **持仓 Top**：mobile 3 行 + "看全部"；tablet 5 行；desktop 表格 8 行（含列：名称、数量、估值、持仓占比、今日 P/L、年化）。

## 7. 边界状态对照表

| 状态 | 触发 | UI |
|------|------|-----|
| empty | 无任何资产 | Hero `¥ —` + 引导卡 |
| loading | 首次冷启 | 骨架屏 |
| stale | 行情 > 30min | 卡角 ⚠️ + tooltip |
| partial | 部分数据源失败 | 数据正常显示 + 顶部黄色 banner |
| error-sync | 同步失败 | AppBar ○ + Snackbar 重试 |
| network-off | 离线 | 顶部 banner "离线模式（最后同步 14:32）" |
