# 03 · 资产列表 / Assets

## 1. 目标

- 支持多账户、多币种、多大类下，**快速找到一笔持仓**。
- 让用户一眼看出"哪些在涨、哪些在跌、哪些占比最大"。
- 移动端是浏览 + 增删，桌面端额外是批量复盘 + 导出。

## 2. 信息架构

```
Assets
├── 顶部 Filter 栏
│   ├── 分组：账户 / 大类 / 币种 / 标签
│   ├── 类型筛选：股票 / 基金 / 现金 / 加密 / 房产 / 其他
│   ├── 排序：估值 ↓ / 今日 P/L / 持有时长 / 名称
│   └── 搜索框（mobile 折叠到图标）
├── 总计带（按当前筛选）
│   - 资产数 · 总估值 · 平均持有时长 · 总成本
├── 列表 / 表格
└── 底部 FAB（mobile）/ 顶部按钮（desktop）：[+] 添加资产
```

## 5. Hi-Fi 规格（增量）

继承通用 Token，下面只列 Assets 特有。

| 元素 | Light | Dark |
|------|-------|------|
| 卡片 hover | `〈color.bg.surface.hover〉` (M3: surfaceContainerHigh) | 同 |
| 选中 (多选) | `〈color.brand.primary〉` 12% 填充 + 边框 1.5dp | 同 |
| 收益涨/跌 | 见 `02-dashboard.md` 涨跌色 | 同 |
| 持仓为零 | 整行 `opacity: 0.6` | 同 |
| 已归档 | 整行 `opacity: 0.45` + "已归档" 徽章 `surfaceContainerHigh` | 同 |

数字对齐：金额、百分比都靠右对齐 + tabular figures；名称靠左；账户副信息小字 12sp `onSurfaceVariant`。

## 6. 关键交互

- **下拉刷新**：mobile / tablet 触摸支持。
- **筛选持久化**：用 query string，URL 直接反映筛选；返回时恢复。
- **批量编辑** (mobile 长按 / desktop checkbox)：标签、归档、删除。
- **滑动操作** (mobile)：左滑显示 [编辑]，右滑 [删除]（确认 dialog）。
- **空筛选结果**：显示 "没有符合条件的资产" + 一键清空筛选按钮。
- **大数据量**：≥ 100 项时使用 `ListView.builder` + 分组 `SliverStickyHeader`（按账户分组）；desktop 表格用虚拟滚动 (`flutter_lazy_data_table` 或 sliver-based)。
- **行情陈旧**：单个资产估值小角 ⚠️ + tooltip。
- **币种**：默认显示基础币种估值；行尾长按可切到原币展示当前条目。

## 7. 边界状态

| 状态 | UI |
|------|-----|
| 0 资产 | Empty State：插画 + CTA "添加你的第一项资产" |
| 0 筛选结果 | 文案 + "清除筛选" 按钮 |
| 100+ 项 | 分组 sticky header + 性能：避免 `ListView` 全量构造 |
| 部分行情失败 | 顶部黄色 banner + 失败行 ⚠️ |
| 离线 | banner + 列表只读（禁用 [+]） |

## 8. 数据形状

```dart
class AssetListRow {
  final String id;
  final AssetType type;          // stock, fund, cash, crypto, realEstate, other
  final String symbol;           // AAPL / 0700.HK
  final String name;             // 显示名
  final String? logoUrl;         // 可空
  final String accountName;
  final Decimal quantity;
  final Money costAvg;           // 平均成本（原币）
  final Money currentPriceLocal; // 现价（原币）
  final Money valueBase;         // 估值（基础币种）
  final double dayPLPct;
  final double totalReturnPct;
  final DateTime? quoteAsOf;     // 行情时间
  final bool archived;
  final List<String> tags;
}
```

## 9. 排序与分组

| 排序 | 默认 | 备注 |

分组：账户 / 大类 / 币种 / 标签（互斥单选）。

## 10. 走查检查项（节选）

- [ ] 名称过长（> 18 字符）是否截断 + tooltip？
- [ ] HSBC 港股账户名等英文 + 中文混排是否对齐？
- [ ] 数字 8 位 + 千分位仍能完整展示（mobile 不换行）？
- [ ] 0 数量、负估值（融资）、外币是否都能正确显示？
