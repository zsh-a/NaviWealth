# 08 · 再平衡 / Rebalance

## 1. 目标

- 一目了然看到"我现在的配置 vs 目标配置"的偏离。
- 给出"卖什么、买什么、多少钱"的可执行建议。
- 一键把建议转成草稿交易（不自动执行）。

## 2. 信息架构

```
Rebalance
├── 目标方案选择（保守 / 平衡 / 激进 / 自定义）
├── 配置预览（实际 vs 目标，带偏离条）
├── 建议交易列表（按"先卖后买"或税务最优排序）
├── 执行按钮 → 一键填入 /activity/trade（每条独立草稿）
└── 设置：阈值（仅显示偏离 ≥ X%）/ 频率提醒
```

## 4. 算法说明

- **偏离**：`|实际权重 - 目标权重|`。整体偏离用 `sum(|...|) / 2` 表示（同义于 *one-sided drift*）。
- **建议**：
  1. 计算每个大类需要变动的金额：`Δ_i = (target_i - actual_i) × totalValue`。
  2. 在 `Δ_i > 0`（要买）的类里挑流动性好的代表性持仓 / 现金。
  3. 在 `Δ_i < 0`（要卖）的类里挑偏离最大的个券；尽量选**不会触发税务的批次**（FIFO/LIFO/Specific Lot —— 用户可选）。
  4. 估算费用 = 卖出金额 × 估计费率 + 买入金额 × 估计费率。
- **阈值**：默认仅在某大类偏离 ≥ 5% 或整体偏离 ≥ 5% 时弹出建议。

## 5. 关键交互

- **方案切换**：保守/平衡/激进 是预设权重；"自定义" 进入编辑页（饼图拖动 + 数字输入，sum 必须 = 100%，>100% 时红色提示）。
- **生成草稿**：跳到 [`05-add-transaction.md`](./05-add-transaction.md) 的"批量草稿"队列；用户可逐笔确认/修改/删除。
- **忽略本次**：记录到本地"已忽略 7 天"，期间不再提醒（由 Settings 中的提醒频率覆盖）。
- **历史**：底部 "查看上次再平衡 (2025-12-15)" 链接，跳到只读视图。

## 6. Hi-Fi 规格（增量）

| 元素 | Light | Dark |
|------|-------|------|
| 偏离条 实际部分 | `〈color.brand.primary〉` | 同 |
| 偏离条 目标线 | `〈color.fg.muted〉` 1.5dp 虚 | 同 |
| 偏离 ≥ ±5% 警示 | `error.container` 背景 + `error` 文字 | 同 |
| 偏离 ≥ ±10% 严重 | `error` 实色 + 白字 | 同 |
| 在范围内 | `success.container` 背景 (柔和) | 同 |
| 建议卖 行 | 左 4dp 涨色（CN 红 / Intl 红 - 取决于"扣减"语义实际是减仓） |  |
| 建议买 行 | 左 4dp 跌色（CN 绿 / Intl 绿 - 增仓） | |

> 注意：再平衡里"卖" / "买" 与"涨/跌"是不同语义。为避免混淆，推荐 **卖用橘（warn）/ 买用蓝（info）**，与涨跌色解耦。这一规则写入 [`10-settings.md`](./10-settings.md) 的"颜色语义" 表。

## 7. 边界状态

| 状态 | UI |
|------|-----|
| 配置 = 目标（无偏离） | 大型空态：✅ "组合处于目标范围内" + 上次再平衡时间 |
| 现金为 0 且需要买入 | 提示 "建议先卖出再买入" 或 "需要补入现金 ¥xx" |
| 自定义权重未保存 | 顶部 banner 提示 + 二次确认 |
| 跨币种再平衡 | 显示注释 "估算用 14:32 汇率"，并用基础币种统一表达 |

## 8. 数据形状

```dart
class RebalancePlan {
  final TargetAllocation target;        // 大类 -> 权重
  final ActualAllocation actual;
  final List<Drift> drifts;             // 含警示等级
  final List<SuggestedTrade> trades;    // 卖/买/转账
  final Money estimatedFees;
  final Money estimatedTaxes;
  final double driftAfterPct;
}
```
