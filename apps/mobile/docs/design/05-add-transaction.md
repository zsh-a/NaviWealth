# 05 · 添加交易 / Add Transaction

## 1. 目标

- 30 秒内录完一笔常规买/卖单。
- 错误优先在客户端拦截（数量/价格 ≤ 0、日期未来、币种不匹配）。
- 复用：上次输入的账户 / 资产 / 手续费方案作为默认。

## 2. 交易类型

| 类型 | 字段 | 备注 |
|------|------|------|
| 买入 (buy) | 资产、数量、单价、日期、币种、手续费、账户、备注 | 默认 |
| 卖出 (sell) | 同上 | 校验数量 ≤ 当前持仓 |
| 分红 (dividend) | 资产、金额、日期、币种、税金、再投资 (toggle) | 再投资勾选会衍生买单 |
| 拆股 (split) | 资产、比例 (1→N)、日期 | 仅记录，无现金流 |
| 转账 (transfer) | 来源账户、目标账户、金额、币种、日期、汇率（跨币种） | 资金账户内转 |
| 调整 (adjust) | 资产、数量调整 / 成本调整、日期、原因 | 用于纠正历史误差 |

> 类型切换不重新打开页面 — 顶部 SegmentedButton。表单字段动态显示 / 隐藏。

## 4. 字段交互

### 4.1 资产选择
- 输入即过滤（fuzzy match `symbol` + `name`）。
- 列出 "最近 10 个" 与 "持仓中"。
- 未找到时提示 [创建新资产]，跳到 Asset 创建子流程后回填。
- 桌面键盘：上下键导航，回车选中，`/` 进入搜索。

### 4.2 数量 / 价格
- 仅允许小数（按资产精度，股票 4 位、加密 8 位、外币现金 2 位）。
- 输入框右侧显示单位（"股 / 份 / 个 / HKD"）。
- 数量 = 0 或 < 0 → 红色错误。
- 卖出时数量大于当前持仓 → inline 错误 "持仓 200 股，最多卖出 200 股"。

### 4.3 日期
- 默认今天；点击弹日历；不允许未来日期（除非"调整"类型）。
- 历史日期触发"使用历史价格 ¥xx.xx？" 一键填入。

### 4.4 币种
- 自动跟随资产的原币（不可改 — 灰显但可点击查看为什么）。
- 跨币种现金转账：来源 / 目标币种独立 + 显示汇率字段。

### 4.5 手续费 / 税金
- 默认隐藏，点击 "+ 费用与税金" 展开。
- 记忆该账户的"上次费率" 作为下次默认。

### 4.6 估算带（实时）
- 小计 = 数量 × 价格
- 合计 = 小计 + 手续费 + 税金（卖出时减去）
- 基础币种估值 = 合计 × 当前汇率（标注汇率版本与时间）
- 汇率缺失：显示 ⚠️ "汇率不可用，将以当时收盘汇率回填"

## 5. 校验

| 字段 | 规则 |
|------|------|
| 资产 | 必选 |
| 账户 | 必选 |
| 数量 | > 0；卖出时 ≤ 当前持仓 |
| 价格 | > 0；分红时不要求 |
| 日期 | ≤ 今天（调整类型例外） |
| 币种 | 与资产币种一致；跨币种时强制汇率字段 |
| 手续费 / 税金 | ≥ 0 |

错误显示在字段下方红色 1 行；"保存"按钮在有错误时禁用。

## 6. 提交流程

```
保存 → 客户端校验 → 写入本地 DB
       ├─ 成功：Snackbar "已添加 · [撤销]" (8s)
       └─ 失败：Dialog "保存失败" + 详情 + 重试

保存并继续（仅 desktop / tablet）：保留账户、资产、日期，清空数量/价格，焦点回到数量。
```

| 元素 | Light | Dark |
|------|-------|------|
| 表单 BG | `surface` | 同 |

| 估算带 BG | `surfaceContainer` | 同 |
| 错误色 | `error` | `error` |
| Segmented 选中 | `secondaryContainer` | 同 |

字段间距：`space.4` 16dp（同行）/ `space.5` 24dp（区块间）。

## 8. 关键交互

- **键盘 (desktop)**：`Tab` 顺序固定；`⌘ + Enter` = 保存并继续；`Esc` 关闭。
- **撤销**：保存后 Snackbar 提供 8 秒撤销窗口；超时后只能从交易列表删除。
- **模板**：底部 "另存为模板" 把当前字段（除日期/数量/价格）保存为快捷入口（设置里管理）。
- **批量录入**：CSV 导入入口（独立流程，不在本页）。

## 9. 边界状态

| 状态 | UI |
|------|-----|
| 离线 | 表单可填，提示"将在网络恢复后同步"，但价格自动填充禁用 |
| 资产不存在 | "创建新资产" 子流程嵌入 |
| 历史日 + 没有当时价 | inline 提示 + 允许手动填 |
| 大额（> 1e7） | 二次确认 dialog "确认录入 1,234 万元交易？" |

## 10. 数据形状
