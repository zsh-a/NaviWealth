# 12 · 可用性自查 / Design Review Checklist

> 走查工程师 / 设计师 / 自检清单。每个页面 PR 至少跑一遍以下检查。

## 1. 通用走查（适用所有页面）

### 1.1 信息层级
- [ ] 页面"主标题 → 主指标 → 次要内容"层级在 3 秒内可识别。
- [ ] 主操作按钮（CTA）只有 1 个，视觉权重最高。
- [ ] 次操作（如"取消"、"忽略"）视觉弱化但不隐藏。

### 1.2 响应式
- [ ] 在 360×640 / 768×1024 / 1440×900 三档下都能使用且无横向滚动。
- [ ] mobile 单手可触达主要按钮（屏下三分之一）。
- [ ] desktop 主内容居中，最大宽 ≤ 1280dp（卡片）/ 不限宽（表格）。

### 1.3 暗黑模式
- [ ] 所有插画 / 图标在 dark 下颜色对比度 ≥ 4.5。
- [ ] 涨/跌色在 dark 下不刺眼（亮度 +10% 而非更深）。
- [ ] 表面色层次：surface < surfaceContainer < surfaceContainerHigh（dark 下 hover 有可识别变化）。
- [ ] 切换 light↔dark 不闪屏（200ms cross-fade）。

### 1.4 国际化
- [ ] 中文 / 英文 / 日文 字符串在 1.0 / 1.5 textScaleFactor 都不溢出 / 截断。
- [ ] 日期 / 数字按 locale 格式化（`intl`）。
- [ ] 货币符号位置（前置 ¥ / 后置 €）按 locale。

### 1.5 可访问性
- [ ] 所有交互元素有 Semantics label（含图标按钮）。
- [ ] 焦点环可见（键盘导航）。
- [ ] 颜色不是唯一信息载体（涨跌也用三角图标）。
- [ ] 触发区 ≥ 44×44dp。
- [ ] 屏幕阅读器读金额"¥1,283,452.10" 输出"一百二十八万..."（按 locale）—— 用 `Semantics(label:)` 显式重写。
- [ ] 对比度：正文 ≥ 4.5 / 大字 ≥ 3 / 图形 ≥ 3。

### 1.6 数字与日期
- [ ] 所有金额、百分比、数量使用 tabular figures。
- [ ] 千分位规则与设置一致（西式 / 中式万分组）。
- [ ] 日期"昨天 / 今天 / 1 周前 / 2025-04-15"按距离选择简写还是完整。
- [ ] 时区：所有时间戳显示用户本地时区（由 `DateTime.toLocal()`）。

### 1.7 加载 / 错误
- [ ] 首次加载有骨架屏，不是空白。
- [ ] 错误有可执行操作（重试 / 联系支持 / 切到离线）。
- [ ] 没有"未知错误"无信息提示。
- [ ] 网络断开时，可读、不可写功能仍可用。

### 1.8 性能
- [ ] 列表 ≥ 100 项使用 `ListView.builder` 或虚拟滚动。
- [ ] 图表 ≥ 1000 数据点降采样。
- [ ] 路由切换 < 240ms 显示首屏内容（含骨架）。

## 2. 页面专项

### 2.1 Dashboard
- [ ] 净值 0 / 极大值（≥ 1e10）的展示合理。
- [ ] 行情陈旧标记可见。
- [ ] 空态有 onboarding CTA。
- [ ] 数字滚动不超过 800ms。
- [ ] 触发"问 AI"长按上下文菜单工作。

### 2.2 资产列表
- [ ] 长名 / 长账户名截断 + tooltip。
- [ ] 桌面表格列宽记忆。
- [ ] 大数据量分组 sticky header 工作。
- [ ] 滑动 / 长按 / 多选互不冲突。

### 2.3 资产详情
- [ ] 拆股后 lots 数量正确。
- [ ] 跨币种"累计回报"标注用基础币种或原币。
- [ ] 图表事件标记清晰（不遮挡）。
- [ ] Tab 切换保留滚动位置。

### 2.4 添加交易
- [ ] 软键盘弹起后 CTA 可见。
- [ ] 数字键盘对小数支持（iOS）。
- [ ] 类型切换字段动态出现 / 隐藏不丢已填值。
- [ ] 撤销 Snackbar 在多次保存时合并。

### 2.5 分析
- [ ] 区间切换图表平滑。
- [ ] 多基准独立开关。
- [ ] tooltip 边缘反向。
- [ ] 配置 Tab 颜色一致。

### 2.6 FIRE
- [ ] 进度 0% 仍展示。
- [ ] 蒙特卡洛扇形对色盲清晰。
- [ ] 滑块拖动 ≥ 30fps。
- [ ] 跨越里程碑只祝贺一次。

### 2.7 再平衡
- [ ] 自定义权重 sum 校验。
- [ ] 卖/买色与涨跌色解耦（橘 / 蓝）。
- [ ] 生成草稿后状态变更。

### 2.8 AI 对话
- [ ] 流式光标稳定。
- [ ] 引用项失效优雅降级。
- [ ] 隐私模式下出站 prompt 脱敏，UI 显示原值。
- [ ] 拒绝模板触发条件正确。

### 2.9 设置
- [ ] 所有切换实时预览（颜色、字体、涨跌色）。
- [ ] 危险操作（清空、删除账户）二次确认。
- [ ] Web 平台兼容降级（生物识别等）。

## 3. 暗黑模式专项（双版本对比）

每个页面在 light / dark 下截图对比。检查：
- 图标可见性
- 卡片 / 背景层次
- 涨跌 + 强调色饱和度
- 阴影是否过强（dark 下应几乎不可见，靠表面色对比）
- 图表线条与背景区分度

## 4. 空态 / 错误态对照

每个页面给出：

| 状态 | 期望 |
|------|------|
| 第一次进入（empty） | 引导 CTA + 插画 |
| 加载中（loading） | 骨架屏 |
| 部分数据（partial） | 顶部 banner + 数据正常显示 |
| 全部错误（error） | 错误页 + 重试 |
| 离线（offline） | 顶部 banner + 写操作禁用 |
| 数据陈旧（stale） | 单元格 ⚠️ + tooltip |

## 5. 用户旅程冒烟（手动）

跑一遍以下旅程，每步打勾：

1. **首次使用** → 安装 → 启动 → 引导 → 添加第一项资产 → 看 Dashboard
2. **日常查询** → 启动 → Dashboard 下拉刷新 → 点 Top 持仓 → 资产详情看 30 天
3. **录入交易** → / → +Tab → 添加交易 → 选 AAPL → 填 100×195 → 保存 → 资产列表看到
4. **月度复盘** → / Analytics → 切 1M → 看归因 → 切 Allocation → 看大类
5. **再平衡** → / Rebalance → 平衡方案 → 查看建议 → 生成草稿
6. **FIRE 检查** → / FIRE → 编辑参数 → 拖动滑块 → 看 ETA 变化
7. **AI 提问** → /chat → "AAPL 这个月涨了多少？" → 看回答 + 引用 → 点引用跳转

## 6. PR 自检模板

```
### Design Review

- [ ] 已在 mobile / tablet / desktop 三档下截图（light + dark）
- [ ] 已检查空态 / 加载 / 错误 / 离线 / 陈旧 5 种状态
- [ ] 屏幕阅读器关键流程已朗读测试
- [ ] textScaleFactor 1.5 不溢出
- [ ] 对应文档：apps/mobile/docs/design/<n>-<name>.md
```
