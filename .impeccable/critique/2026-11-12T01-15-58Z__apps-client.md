   four-column long labels, light/dark contrast, scaled type, keyboard Enter and

   native host and capture all roots/editor in light/dark plus narrow/large type.
   Suggested command: `$impeccable audit apps/client`.
2. **P2 — Shell uses the solid material fallback.** Core has backdrop API and
   Android supports blur from API 31, but platform capability selection and
   suspending glass for every modal have not been implemented. Keep solid until
   both capability and modal lifetime are integrated and natively verified.
   Suggested command: `$impeccable harden apps/client`.
3. **P2 — A filtered save is explained rather than revealed.** The receipt tells
   users to inspect dates/filters; it does not scroll or switch to the saved row.
   This preserves filters but adds work for a record outside them. Validate the
   receipt in the native host before adding a separate reveal action.
   Suggested command: `$impeccable polish apps/client`.
