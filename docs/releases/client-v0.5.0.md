FinanceOS Rust 客户端改为温润纸感工作台：暖白与墨绿配色，金额使用内置 Manrope 字体，今日／流水／财富／规划四个入口保持不变。

- 浅深色主题全面更新，配有统一的线性分类图标。今日页显示月结余主数字，并新增预算可用、单日最高两张迷你卡；财富页增加资产构成条和净资产趋势；规划页直接列出预算余额、到期安排和目标进度。
- 金额统一显示千分位，负号紧贴数字；流水币种与账户币种或基础币种相同时不再显示。
- 数据刷新时保留当前内容、滚动位置和焦点，不再切换为整页加载提示。
- 预算超支时，今日卡片、记账弹层和流水预算模块显示同一个超出百分比。持仓部分缺价时，仍显示该币种已知的资产与负债。近 30 天时点不足时，趋势图改用全部历史。
- 分类快捷筛选改按分类身份查询，重命名分类或使用自定义分类后仍然有效。今日日支出改用只读按日汇总，搜索和分页不再触发整月扫描。
- 记账弹层的分类选择改为带图标的自适应网格，预算调额只编辑额度。

验证：247 项 Rust 工作区测试、23 个套件、格式检查和严格 Clippy 通过。GTK 原生界面已截图验收，覆盖浅深色、360／390／411 宽度以及 1.0／1.3 字号。

包信息：`com.naviwealth.client`，版本 `0.5.0`，build `7`，支持 `arm64-v8a` / `armeabi-v7a`。沿用 0.3.1 起的固定发布签名，可覆盖安装 0.3.1 及以上版本。

Manrope 字体（OFL）已打包，体积约 25 KB，仅用于数字与拉丁文字，中文使用系统字体。Android、iOS、Web 的字体加载、软键盘与触摸手感尚未在设备上验收；超大账本的按日汇总性能尚未做基准测试。

本轮未改 Flutter 客户端、数据模型及财务写入、余额规则；财务仓储层只新增只读查询。
