完成 FinanceOS 核心财务闭环，默认进入流水，通过今日／流水／财富／规划四个入口查看事实并执行操作。

- 日常财务：账户、期初余额、收支和跨币种转账；搜索筛选、编辑删除、归档恢复。
- 财富与投资：资产建档、持仓买卖、FIFO 成本与收益、分红拆股、手动估值与汇率；明确缺失的价格和估值依据。
- 预算与规划：分类预算及贡献流水、周期收支、贷款本息与还款撤销、30／90 天现金跑道、目标与定投、配置再平衡和 FIRE 情景。
- 财务运营：系统 CSV 选取、逐行复核和重复预览、整批入账与撤销、账户对账、收件箱及五步月结快照。
- 界面：深海青浅色／深色主题、紧凑数字和流水、保存后的原位反馈、草稿保护、日期选择和大字体适配。

验证：202 项 Rust 工作区测试、22 个套件及严格 Clippy 通过。Android 15 / API 35 x86_64 模拟器验证了连续记账、转账、编辑删除、重启持久化，以及预算、估值、CSV 复核撤销、对账和月结；浅色／深色、360dp／1.3 字号及关闭动画状态已检查。

包信息：`com.naviwealth.client`，版本 `0.3.1`，build `5`，支持 `arm64-v8a` / `armeabi-v7a`。
