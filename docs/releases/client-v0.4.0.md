FinanceOS Rust 客户端更新为 quiet workspace：中性纸墨、石墨主操作和钢蓝焦点，保留今日／流水／财富／规划四个入口。

- 浅深色主题整体更新；扁平流水、独立四列分类与选中勾、清晰的收支／净资产金额层级。
- 金额、对方和备注支持 Enter 保存；共享控件提供焦点环，离开确认统一以“继续填写”为主操作。
- 今日就地记账，保存后显示本地回执和对应流水高亮；无需切换至流水页。
- 新建和删除普通记录提供 60 秒撤销、剩余秒数及失败重试，覆盖业务标签和详情页。编辑不提供删除式撤销；重启后不保留撤销入口。
- 删除恢复只还原该次删除的有效分录，防止编辑历史重复计入余额；账户缺失、来源受限或分录未同步完整时拒绝恢复。
- 预算接近上限及达到／超出预算同时提供配色与文字提示，现金预测图采用独立数据色。

验证：208 项 Rust 工作区测试、22 个套件、格式检查和严格 Clippy 通过，覆盖今日就地保存、回执／高亮、撤销后的余额与记录、Enter 提交及分类选中语义。
