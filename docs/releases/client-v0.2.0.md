# NaviWealth client 0.2.0（build 3）

本版完成 FinanceOS 日常记账闭环，默认先看流水，保留快速记账入口。

- 账户与期初余额、收入、支出、同币种与跨币种转账。
- 按月或全部时间查看流水，支持搜索、账户与类型筛选。
- 记录详情、编辑、删除确认，账户资料编辑、归档、恢复及空账户删除。
- 本地数据持久化、加密备份与 Android 系统文件选择器导出/恢复。
- 重做浅色与深色界面、数字排版、紧凑筛选与受保护的编辑表单。
- 修复 Android 输入框保留焦点时吞掉按钮点击、弹层被详情页遮挡、底部操作
  被系统导航栏覆盖等问题。

验证：141 项 Rust 工作区测试、严格 Clippy 和格式检查通过。Android 15 / API 35
x86_64 模拟器已实际验证连续记账、转账、编辑删除、重启余额保留、账户操作、搜索
筛选、外部加密备份导出、错误口令保留数据与正确口令恢复。另已检查深色输入、
360dp / 1.3 字号以及长账户名；界面复审的三项修正均已复核解决。

发布 APK 支持 `arm64-v8a` 与 `armeabi-v7a`，使用调试签名。
ARM 实体机、iOS、TalkBack、predictive Back 和真实云端同步尚未完成验收。
本版范围是日常财务；投资估值、预算/FIRE、旧 Flutter 数据迁移与其他领域的完整
界面不在本轮范围内。
